# 🩺 Azure Functions Doctor — GitHub Action
**Azure Functions Doctor** is a GitHub Action that automatically diagnoses issues in your Python-based Azure Functions projects.
It helps you catch common configuration and structure problems **before deployment**.
This action checks your project for:
👉 Designed to prevent runtime failures and deployment issues
```yaml
name: Azure Functions Doctor
on: [push, pull_request]
jobs:
  doctor:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Run Azure Functions Doctor
        uses: yeongseon/azure-functions-doctor@v0.17.0

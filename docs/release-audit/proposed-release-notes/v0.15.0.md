## v0.15.0 (2026-03-08)

### Notes

- This is a breaking change for users still relying on Azure Functions Python v1 checks.
- PyPI release 0.15.0 corresponds to the
0.15.0 Git tag and current main release workflow.

### Highlights

- Remove Azure Functions Python v1 support and focus the tool on Azure Functions Python v2 projects.
- Align tooling, CI, release automation, and repository maintenance with the rest of the project set.
- Improve documentation, branding, and README demo assets.
- Expand example coverage and raise overall test coverage to 90%.
- Publish releases through PyPI Trusted Publishing.
